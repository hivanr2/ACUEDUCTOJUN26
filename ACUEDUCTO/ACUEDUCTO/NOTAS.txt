Issue seems to be related to the way the Self-signed certificate gets generated from IIS. My issue got resolved after I used powershell to create the self-signed certificate.

Run Powershell as admin

Paste the following command: New-SelfSignedCertificate -FriendlyName YourCertifcateName -DnsName YourServer -KeyUsage DigitalSignature -NotAfter (Get-Date).AddYears(20)

New-SelfSignedCertificate -FriendlyName AcueductoJAC -DnsName Acueducto -KeyUsage DigitalSignature -NotAfter (Get-Date).AddYears(20)

Replace the “YourCertificateName” to one of your choice.

Replace the “YourServer” to the hostname of the server.

Then press Enter.

The self-signed cert gets created and saved and is now available in IIS.

Open IIS and bind the newly created certificate to the website on the https port.

Refresh your webpage.

To send an email from your server to another SMTP server like smtp.gmail.com using ASP.NET, you can follow these steps. Please note that you need to ensure that your server allows outbound connections on port 587 and that your Gmail account settings allow access from less secure apps.

1. **Set Up Your Email Message**: Use the `System.Net.Mail` namespace in ASP.NET to create and configure your email message.

2. **Configure SMTP Client**: Set up your SMTP client with Gmail's SMTP server details.

Here's a sample code snippet in C#:

```csharp
using System.Net.Mail;

// Set up the email message
MailMessage message = new MailMessage();
message.From = new MailAddress("your-email@gmail.com");
message.To.Add(new MailAddress("recipient@example.com"));
message.Subject = "Test Email";
message.Body = "This is a test email sent from ASP.NET.";

// Configure SMTP client
SmtpClient client = new SmtpClient("smtp.gmail.com", 587);
client.Credentials = new System.Net.NetworkCredential("your-email@gmail.com", "your-password");
client.EnableSsl = true;

// Send the email
client.Send(message);
```

**Important Notes**:
- Replace `"your-email@gmail.com"` and `"your-password"` with your actual Gmail credentials.
- Ensure that your server allows outbound connections on port 587.
- Make sure your Gmail account settings allow access from less secure apps.

If you encounter any issues, please check the following:
- Verify your Gmail credentials.
- Ensure that your server's firewall settings allow outbound connections on port 587.
- Check if your Gmail account settings allow access from less secure apps.

If the issue persists, please provide more details about the error message you are receiving, and we will be happy to assist you further.

For more detailed information, please refer to our Knowledge Base article: [How do I send an email using ASP.NET?](https://cp.adaptivewebhosting.com/index.php?rp=/knowledgebase/50/How+do+I+send+an+email+using+ASP.NET%3F.html)

   - `MyBase.Client` — Blazor **WebAssembly** (WASM) que contiene toda la interfaz de usuario (componentes, páginas, servicios cliente HTTP).

10. Seguridad contra XSS, CSRF, SQL Injection; CSP headers, HSTS, HTTPS obligatorio.
11. Funciones básicas GDPR/CCPA: exportación y borrado de datos.
